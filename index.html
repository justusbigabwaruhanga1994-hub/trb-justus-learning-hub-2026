How the Digital Library Works

Keep your original files in Google Drive and add the individual resources you want to publish.

1. Upload to Google Drive

Upload your PDF, document or learning material. Use a clear name, such as “Primary 4 Mathematics - Fractions”.

2. Allow free viewing

For resources you want to share publicly, set General access to Anyone with the link - Viewer.

3. Add it to the website

Add each resource's title, level, subject, description and share link to the resource list in index.html.

4. Make a QR code

Generate a QR code from a resource link. Test it with a phone before printing.
